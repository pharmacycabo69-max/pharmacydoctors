## Sistema visual V5
- **Escenario azul marino** en el hero de cada página, con un degradado radial sutil y una línea salvia inferior.
- **Cormorant Garamond** para los títulos (h1/h2), con énfasis en cursiva salvia, y **Public Sans** para el texto y las etiquetas.
- **Etiquetas editoriales** en mayúsculas espaciadas con raya y **secciones numeradas** (01, 02…).
- **Arco** como marco de foto (`border-radius: 999px 999px 14px 14px`), firma visual inspirada en El Arco de Cabo.
- **Barra de datos** (precio · duración · lugar · quién) y **tarjeta de precio** con lo incluido.
- **Menú de tratamientos** con líneas de puntos hasta el precio, como una carta.
- Botones de 8 px de radio: marfil sobre azul marino como principal, línea como secundario. El verde se reserva para WhatsApp.
- Sin sombras pesadas, sin degradados de colores, sin banners de promoción.
